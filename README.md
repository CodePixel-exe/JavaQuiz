# Java Quiz
This program is a quiz made in Java featuring various types of questions such as, multiple choice, true/false, and hard questions.
The quiz relies on a CSV file to load in questions and saves results to a CSV file such as the player's name and their previous scores.

# How to run
To run this quiz, head over to the releases section for the JavaQuiz repository by clicking here: https://github.com/CodePixel-exe/JavaQuiz/releases and then download the latest version of the jar file.
Once you have downloaded the .jar file, move it to a suitable location (It is recommended to move the jar to the desktop for ease of use).
Open PowerShell in windows and run the following command:

`java -jar "NAME OF YOUR JAR HERE"`

## Check Java version
>[!NOTE]
>Only use this command if you need to check your Java version
Should this not work for some reason run the following command to check for the version of Java on your computer in PowerShell:

`java -version`

This should show you the version of Java you have currently installed.

# Download Java
If this doesn't show anything or you get an error in PowerShell go to the official website for the Java downloads and download the latest version of Java:
https://www.oracle.com/java/technologies/downloads/
